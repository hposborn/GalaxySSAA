# The Evolutionary Path of Galaxies

- Putting together what we learned about spirals and ellipticals, we can look at changes in galaxy properties with **time**
- In principle, this means measuring changes with **distance** between the early and recent universe.
-v-

# The Evolutionary Path of Galaxies
- Remember we can define distance through redshift $z$, where $ z = \frac{\lambda_{\rm obs}-\lambda_{\rm rest}}{\lambda_{\rm rest}} \sim \frac{H_0 r}{c}$. 
- The age of a galaxy at a given redshift can be given by: $$t(z) \sim \frac{t_H}{1 + z}$$ where $t_H$ is the Hubble time ($H_0^{-1} \sim 14Gyr$). 
- - NB these formula assume _constant expansion_... which is only correct for the local universe!
